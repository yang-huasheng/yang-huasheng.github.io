# 杨欣悦 · 杨花生个人介绍

这是一个纯静态网页，无需安装依赖或构建工具。首屏使用你提供的原始背影照片；作品、活动和荣誉图片按内容归属展示，横向滑动可查看更多，点击可查看完整原图。

## 本地查看

双击打开 `index.html` 即可。所有图片位于 `assets/`，点击任意图片可查看完整原图。

## 上传到 GitHub Pages

1. 将本文件夹内的 `index.html`、`assets/` 和 `.nojekyll` 上传到 GitHub 仓库根目录。
2. 在仓库 Settings → Pages 中选择从 `main` 分支的根目录发布。
3. 保存后等待 GitHub Pages 完成构建。
